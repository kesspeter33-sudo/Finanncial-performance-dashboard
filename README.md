## Overview

This Financial Performance Dashboard was developed using **Power BI** to analyze key business metrics, including sales, revenue, product performance, and regional performance. The dashboard provides interactive visualizations that help stakeholders make data-driven decisions.

---

## Business Problem

Organizations need a clear understanding of their financial performance to identify growth opportunities, monitor sales trends, and improve decision-making.

This dashboard addresses these needs by providing insights into:

* Total Sales Performance
* Average Sales
* Product Performance
* Country Performance
* Salesperson Performance
* Shipment Analysis
